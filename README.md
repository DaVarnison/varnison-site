# varnison-site
Astro static site + Sveltia CMS (/admin), hosted free on GitHub Pages.
- `npm install && npm run dev` to work locally, `npm run build` to build.
- Content lives in `src/content/` (edit via /admin or by hand). Remove the items marked SAMPLE when you add real ones.
- Setup: enable Pages (Settings → Pages → Source: GitHub Actions), set DNS for varnison.com, deploy `oauth-worker/` (see its README).
